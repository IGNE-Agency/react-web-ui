## What's in the system?

The design system is the set of rules, values and components every screen in the product is built from. It starts with the brand and the foundation, and builds up through the principles, including how we write, to patterns. The sidebar lists them in reading order, so if you're new, start at the top.

Read the rules for what you're building before you style it. A component's own rules are on its docs page, under its name in the sidebar, and agents find every rule through `AGENTS.md` in the repository.
