# Brand

ZPM is where care providers prepare, check and submit their declarations. Its brand is small on purpose: one mark, one green, two typefaces and a soft, rounded shape. The rest of this guide is about how those few things are spent.

## The mark

A circle with four petals cut out of it, each pointing at the centre: a cross held in negative space, unchanged by a quarter turn. It is one shape in one colour, so it holds up at any size, down to a browser tab.

## The mark is drawn in the brand colour and nothing else

The mark [takes the brand role](?path=/docs/design-system-foundation-token-architecture--docs#a-component-reads-a-role-never-a-step), so it follows the theme like any other brand fill: a deeper green on light, a paler one on dark. On a brand fill it takes that fill's ink. It is never a status colour, a gradient or an outline.

In code: the file keeps the brand green as its own colour, for the browser tab, which has no stylesheet. Every use in the product sets the colour itself, or the mark stays that one green in both themes.

## The mark is decoration

Wherever it appears, the mark is hidden from assistive technology. Where it is a link, as at the top of the sidebar, [the link carries the name](?path=/docs/design-system-principles-accessibility--docs#every-control-has-a-name-from-exactly-one-mechanism) of where it goes. See [Decoration is `aria-hidden`](?path=/docs/design-system-principles-accessibility--docs#decoration-is-aria-hidden).

## The mark's one movement is a tick

<Beside>

When the mark moves, it winds back, springs a quarter turn past where it started and settles. A quarter turn leaves it looking exactly as before, so the tick can repeat for as long as it needs to: while a page loads, or while a wait runs long. It ticks once when the sidebar's mark is clicked. For a user who asked for less motion it pulses instead. See [Every wait has an indicator](?path=/docs/design-system-foundation-motion--docs#every-wait-has-an-indicator-and-that-indicator-keeps-changing).
