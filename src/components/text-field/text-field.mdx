## Rules

### Clear appears once the field holds a value, and never on one that cannot change

`Clear` decides for itself when it exists: once the field holds a value, and never while the field is disabled or read-only, because a control that cannot change does not offer to be emptied. It carries [a tooltip and an accessible name like any icon-only control](?path=/docs/design-system-principles-interaction--docs#an-icon-only-control-always-has-a-tooltip-and-an-accessible-name), and it sits in the group's padding so a clearable field is no taller than a plain one beside it. Clearing unmounts the button under the pointer, so the same handler puts focus back on the input; see [focus returns after a part removes itself](?path=/docs/design-system-principles-accessibility--docs#focus-returns-after-a-part-removes-itself).
