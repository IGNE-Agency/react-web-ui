## Rules

### A group shows a few faces and counts the rest

The stack shows up to four avatars and folds everyone after them into a count, so a long list of people takes the same room as a short one. The count is a number with its sign, such as "+3", in the reader's own number format.

### Everyone in the group can be found by name

The group carries a name for what the people are, such as "Invitees", and each avatar in the stack is an image named for its person, so a screen reader reads every face it shows. The stack is content, not a control. Only the count is a button: it is named for what it opens, such as "+3, show all invitees", with the count it shows at the start of that name, and it opens a list of everyone by name on hover, on a tap or from the keyboard. A group with no count has no button and no list: its avatars already name everyone in it. The person viewing is marked in that list, in their own words, such as "(you)".

### The prefab is the parts, composed

`AvatarGroup` takes `people` and composes the parts hanging off it, each one element: `Root` names the stack and sets its size, `Avatar` is one overlapping member holding the person's `Avatar`, `Overflow` is the count's button holding a `Count`, rendered as the trigger of a `Popover`, and `Popup` is that popover's surface, named after the group. `List` and `ListItem` are the usual list of everyone, each item an `Avatar` and a `Name`, with a muted `Suffix` after a name. Compose the parts by hand where the stack or the list needs other markup, such as listing only the people the stack leaves out.

```tsx
<AvatarGroup.Root label="Invitees">
	{shown.map(person => (
		<AvatarGroup.Avatar key={person.id} name={person.name}>
			<Avatar
				name={person.name}
				src={person.src}
				size={1.5}
			/>
		</AvatarGroup.Avatar>
	))}
	<Popover.Root>
		<AvatarGroup.Overflow
			label={`+${rest.length}, show all invitees`}
			render={<Popover.Trigger openOnHover />}>
			<AvatarGroup.Count count={rest.length} />
		</AvatarGroup.Overflow>
		<Popover.Portal>
			<Popover.Positioner side="top" sideOffset={8}>
				<AvatarGroup.Popup>
					<AvatarGroup.List>
						{rest.map(person => (
							<AvatarGroup.ListItem key={person.id}>
								<Avatar
									name={person.name}
									src={person.src}
									size={1.5}
								/>
								<AvatarGroup.Name>
									{person.name}
								</AvatarGroup.Name>
							</AvatarGroup.ListItem>
						))}
					</AvatarGroup.List>
				</AvatarGroup.Popup>
			</Popover.Positioner>
		</Popover.Portal>
	</Popover.Root>
</AvatarGroup.Root>
```
